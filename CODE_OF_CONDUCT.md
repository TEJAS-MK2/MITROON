# Code of Conduct

## Our standard

We want MITROON contributions and discussions to be welcoming, constructive, and respectful. Political satire can be sharp; contributors must still treat other people with dignity.

Examples of unacceptable behaviour include harassment, threats, discriminatory language, doxxing, targeted abuse, and publishing private information.

## Expected behaviour

- Critique ideas and code, not people's identity.
- Keep political disagreement civil.
- Give actionable feedback and accept good-faith corrections.
- Respect maintainers' decisions and community boundaries.

## Enforcement

Project maintainers may edit or remove content, close discussions, or restrict participation for behaviour that violates this code. Report concerns privately to the repository maintainers through GitHub.
